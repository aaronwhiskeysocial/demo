## OPERATIONAL LESSONS FROM THIS RUN

1. **Record the link-out URL for every staged item, in this file, at staging time.** The Charred
   Garden Smash was staged Aug 9 with full sourcing notes but **no URL**, and this file never carried
   one. Recovering it at edition time cost a WA Tag-index fetch, four 404 URL guesses and a web
   search. The URL is `https://whiskyadvocate.com/peated-whisky-cocktail-for-summer` — a slug that
   contains none of the words "charred," "garden" or "smash," which is exactly why guessing failed.
   **Every staged entry from now on carries its URL inline.** Applied retroactively above wherever
   the URL was recoverable.
2. **Slack bold markup has been inconsistent across runs, and this run standardised it.** The
   `slack_send_message` tool takes **standard markdown** and converts it — so `*text*` posts as
   *italic*, and `**text**` posts as **bold**. Aug 7 and Aug 13 sent `*text*` and rendered italic
   mastheads and italic headlines; Aug 9 sent `**text**` and rendered bold. The brand spec calls for
   **bolded** headlines, so this run sent `**text**` throughout. **Standing: use `**bold**`.**
   Not surfaced in Notes — it is cosmetic, it now matches spec, and Notes are not a changelog.
3. **Thread replies under old posts are this pipeline's own overflow, not human feedback.** Every
   parent post Jul 31 – Aug 13 carries 1–3 replies; all are PIPELINE STATE continuations from the
   fourteen-run window when pushes were failing. Future runs should read threads to confirm this but
   should not mistake them for Aaron or Adam replying.
